Ensaios virtuais

Para ensaios online do coral e trabalho musical em conjunto, com acesso por link para os participantes.

  • Piano, solfejo e leitura de pautas
  • Quadro colaborativo em tempo real

Verificação de conhecimentos

Avaliações e testes

Para organizar uma sessão de avaliação musical ou teste. O contexto da atividade será identificado no quadro e no convite.

  • Sessão identificada como avaliação
  • Link próprio para cada sessão
  • Participantes entram por convite
♧
Coordenação e organização

Reuniões

Para reuniões virtuais da Direção, coordenação de líderes e encontros de organização do Departamento.

  • Quadro para pautas e anotações
  • Sala própria para cada reunião
  • Convite exclusivo para participantes
Importante: cada vez que abrir uma atividade será criada uma sala nova. Quando iniciar a sessão no quadro, partilhe o link dessa sessão com os participantes. Os links de convite não devem ser reutilizados para atividades futuras.
